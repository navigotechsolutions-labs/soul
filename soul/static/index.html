Official Python SDK (pip install soul-engine) Typed & Retries

1-line typed SDK client with automatic retries and standalone harmonize:

import soul

# 1. Initialize typed client (reads SOUL_API_KEY from env by default)
client = soul.SoulClient(api_key="soul_live_...")

# 2. Sub-2ms cognitive appraisal
appraisal = client.appraise("I was just laid off with zero notice.")
print(appraisal.adversity.primary_domain)

# 3. Flexible harmonization (no user_message required)
result = client.harmonize("Here are 3 steps to fix your bug.")
print(result["harmonized_content"])

1-Line Drop-in Reverse Proxy Stream: true

Change only two lines in any OpenAI/LangChain app with progressive SSE streaming:

from openai import OpenAI

# 1. Any existing codebase changes ONLY these two lines:
client = OpenAI(
    base_url="https://soul.navigotechsolutions.com/v1",
    api_key="soul_live_your_key_here"
)

# 2. Behind the scenes, Soul proxies to the LLM, harmonizes in <1ms, and streams:
stream = client.chat.completions.create(
    model="soul-attuned",  # or gpt-4o, deepseek-chat, claude-3-5-sonnet
    messages=[{"role": "user", "content": "I feel completely overwhelmed today."}],
    stream=True
)
for chunk in stream:
    content = chunk.choices[0].delta.content or ""
    print(content, end="", flush=True)
